## 📱 Download the App

Welcome to the official download repository for the **Erex** mobile app!

Erex is the ultimate server management tool for Minecraft creators. Powered by a distributed, auto-scaling cloud backend, our Android app allows you to completely control your servers, manage players, install mods, and monitor real-time performance directly from your phone.

### How to Install

1. Navigate to the **[Latest Release Page](https://github.com/Seemsyt/EREX-Releases/releases/tag/v1.0.0)**.
2. Under the **Assets** section, tap on the `app-release.apk` file to download it.
3. Open the downloaded file on your Android device.
4. *Note: If this is your first time installing an app outside of the Google Play Store, your phone may prompt you to enable "Install from unknown sources" or "Allow this source" in your settings.*
5. Follow the on-screen prompts to complete the installation.

## ✨ Features

- **Real-Time Console:** View live server logs and execute commands instantly with zero latency.
- **Smart Auto-Sleep & Wake:** Servers automatically suspend when empty to save resources, and seamlessly wake up the moment a player tries to join.
- **Player Management:** Ban, kick, OP, and track the XUIDs of all online players with a single tap.
- **Mod & Addon Manager:** Search, install, and configure Add-ons (MCPACK/MCADDON) directly from your device.
- **Hardware Metrics:** Monitor live CPU usage, RAM allocation, and disk storage utilization.
- **Cloud File Manager:** Full access to securely edit server properties, whitelist configurations, and world files backed by network-attached storage.
- **Automated Backups:** Trigger instant S3 backups or schedule rolling retention backups to keep your worlds safe.
